# ぐぐががちゃんと仲良くなりタイピング

ブラウザで遊ぶタイピングゲームの試作プロジェクトです。

## 現時点の仮仕様

- 制限時間は 1 分
- 難易度は `初級` `中級` `上級`
- 補足表示
  - 初級: `ぐぐががちゃんLikeなモード`
  - 中級: `ぐぐががちゃんLoveなモード`
  - 上級: `ぐぐががちゃんへの愛が重たいモード`
- ローマ字入力
- 正しく入力できた食べ物やお菓子は 1 個としてカウントし、スコアは `何個プレゼントできたか`
- ミス時ペナルティは将来追加可能な設計にしつつ、現時点では 0
- タイピング成功した食べ物やお菓子は図鑑に登録する
- リザルト演出は `全画面カットイン -> 結果ごとの専用イラスト -> 結果発表`

## ディレクトリ

- `assets/images/characters`: キャラクター参照画像
- `assets/images/cutins`: カットイン画像
- `assets/images/results`: リザルト画像
- `assets/images/foods`: 食べ物やお菓子の画像
- `assets/audio/bgm`: BGM
- `assets/audio/se`: 効果音
- `data/word-lists.js`: 難易度ごとのお題データ
- `docs`: 仕様メモや画像指示書

## いま確認できること

- `index.html` を開くと、`タイトル -> プレイ -> リザルト` の試作導線が見られる
- タイトル画面では難易度を選び、単語データを使ってプレイ画面へ進める
- プレイ画面では 1 分タイマー、スコア、ミス数、現在のお題、ローマ字入力欄を確認できる
- リザルトでは `真正面` と `斜め前` の 2 パターンからカットインをランダム表示する
- 結果ごとに `カットイン -> 結果イラスト -> 結果発表 -> 詳細表示` の流れを再生できる
