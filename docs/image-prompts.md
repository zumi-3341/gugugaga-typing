# 画像生成用プロンプトたたき台

## 共通ルール

- ゲーム用の横長イラスト
- 2D anime illustration
- clean lineart
- soft shading
- character-focused
- no watermark
- no text
- keep the two reference characters recognizable

## 1. カットイン

`result-cutin-zumi`

- ずみちゃん単体
- 画面いっぱいのバストアップから腰上
- 両腕を大きく広げる
- 表情は嬉しそうで、プレイヤーを迎えるような感じ
- 明るい背景エフェクト、ハートやきらめき

## 2. 全然足りない

`result-very-bad`

- ぐぐががが画面の外へぴゅーっと逃げる
- ずみちゃんはショックで固まる
- スピード線やコミカルな勢い

## 3. ちょっと足りない

`result-bad`

- ぐぐががが振り返ってバイバイと手を振る
- ずみちゃんはしょんぼり
- 少し切ないがかわいい

## 4. ぎりぎりクリア

`result-clear`

- ぐぐがががおっかなびっくりしながらずみちゃんにだっこされている
- ずみちゃんは満面の笑み
- 緊張と幸福が同時に見える

## 5. 十分にクリア

`result-good`

- ぐぐががが自分からずみちゃんにぎゅっと抱きつく
- ずみちゃんがうれしすぎてよだれを垂らしつつ抱き返す
- コミカルで勢いのあるごほうび感

## 6. ノーミスクリア

`result-perfect`

- ずみちゃんとぐぐががの結婚式
- きらきら美麗なウェディング風
- ネタとして本気でロマンチック
- ほかの結果より華やかで特別感を強く
