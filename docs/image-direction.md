# イラスト方針メモ

## キャラクター

- `ずみちゃん`
  - ちび頭身
  - グレー系ボブ
  - メガネ
  - 黒と白のクラシカルな衣装
  - 上品でかわいいが、感情表現は大きめ
- `ぐぐがが`
  - 黒いペンギン風の着ぐるみ、ぬいぐるみ感
  - 中の女の子の顔が見える
  - きょとん、警戒、喜びが見えるキャラ

## 全体トーン

- かわいい
- コミカル
- 少しシュール
- 基本はデフォルメ寄り
- ただし `ノーミスクリア` だけはネタとしてキラキラ美麗寄り

## リザルト画像一覧

1. `result-very-bad`
   - ぐぐがががぴゅーっと逃げ出す
   - ずみちゃんはショック
2. `result-bad`
   - ぐぐがががバイバイして去る
   - ずみちゃんは落ち込む
3. `result-clear`
   - ぐぐがががおっかなびっくりしながらずみちゃんにだっこされる
   - ずみちゃんは満面の笑み
4. `result-good`
   - ぐぐががが自分からぎゅーっと抱きつく
   - ずみちゃんがよだれを垂らして抱き返す
5. `result-perfect`
   - ずみちゃんとぐぐががが結婚式を挙げている
   - コミカルではなく、ネタとして美麗でキラキラした演出

## カットイン

- `result-cutin-zumi`
  - ずみちゃんが画面いっぱいに出る
  - 腕を広げて「おいでー♪」と言っている雰囲気
  - リザルトに入る直前のごほうび演出
